### C.1 Test statistic

For a sequence `x_1, …, x_n`, define prefix residues:

```text
S_0 = 0
S_j = (x_1 + … + x_j) mod m.
```

A contiguous span `i+1 … j` is divisible by `m` exactly when:

```text
S_i = S_j.
```

Therefore the total hit count is:

```text
H_m = Σ_r C(f_r, 2),
```

where `f_r` is the frequency of prefix residue `r`.

### C.10 Reference implementation

```python
from __future__ import annotations

import math
import random
from collections import Counter
from typing import Iterable, Sequence


def contiguous_hits(values: Sequence[int], modulus: int = 11) -> int:
    residue = 0
    frequencies = [0] * modulus
    frequencies[0] = 1
    hits = 0

    for value in values:
        residue = (residue + value) % modulus
        hits += frequencies[residue]
        frequencies[residue] += 1

    return hits


def permutation_tail(
    values: Sequence[int],
    threshold: int,
    trials: int,
    seed: int,
    modulus: int = 11,
) -> tuple[int, float]:
    rng = random.Random(seed)
    work = list(values)
    exceedances = 0

    for _ in range(trials):
        rng.shuffle(work)
        if contiguous_hits(work, modulus) >= threshold:
            exceedances += 1

    # Add-one correction.
    p_value = (exceedances + 1) / (trials + 1)
    return exceedances, p_value
```

The high-trial executions used an optimized implementation with independent `mt19937_64` seeds and uniform Fisher–Yates shuffling. Independent Verification replicated the statistic with a portable C++17 implementation using explicit rejection-sampled bounded draws; the verification source and output are retained with the supporting audit package.

Author: Dean Thomas Coombs · [490d.com](https://490d.com/)

Open **[index.html](index.html)** after extracting this package for offline reading.

This collection preserves the published versions of:

- **The Cross at the Center of Time**: introduction and contents plus all 18 chapters.
- **Celestial Signs of the First Advent**: introduction and contents plus all 16 chapters.
- **The Birth and Cross of Christ in Symbolic Time**: the integrated companion study, including the October 20 v3 replacement and its editable 3 + 4 + 3-year table-diagram.

There are **37 pages**, **127 figure placements**, **124 unique hosted figure URLs**, and **127 tables**. Figure files are preserved locally, including the current Paleo-Hebrew replacement chart. The companion contains 14,289 words.

## Preservation layers

| Path | Purpose |
| --- | --- |
| `original-pages/` | Original public HTML response bytes, unchanged. These full pages retain their original remote URLs and website navigation. |
| `reading/` | Derived offline reading copies. Article text and tables are unchanged; chapter links and figure references are localized. Responsive picture sources are removed so each figure uses its preserved original image file. |
| `assets/` | Original bytes of the article figure files served by the published image URLs. |
| `capture-inventory.json` | Source URLs, capture timestamps, HTTP response headers, WordPress IDs, original HTML hashes, figure provenance, and file metadata. |
| `SHA256SUMS.txt` | SHA-256 checksums for every collection payload file. |
| `VERIFICATION.json` | Coverage and local-navigation verification results. |
| `RIGHTS-AND-EDITIONS.txt` | Rights and edition scope, including preserved third-party credits. |

The offline copies retain the article's local styles. Their minimal reading wrapper uses local font fallbacks. External reference links remain external; their destinations and external web fonts are outside this bounded capture. Website-wide menus, search, widgets, analytics and comment forms are retained only in the unchanged original HTML and are not included in the offline reading copies.

## Edition rule

October 20, 2026 is the capture date. It does not assert that every chapter was revised on that date. Source qualifications, chronology conventions, source-note wording, and copyright notices are retained. This is a published-book collection with its own provenance, not an addition to the canonical `File_00` research series.

The separately preserved Unified Chronology source corpus and its older releases retain their own contents, dates, and rights terms. Use the live canonical Markdown and its active controls when interpreting that corpus.

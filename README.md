# 490d Unified Chronology — Canonical Markdown Corpus

Canonical Markdown source corpus of the **490d Unified Chronology Knowledge Catalog** ([490d.com](https://490d.com/)) — biblical chronology across the Masoretic Text, Septuagint, Samaritan Pentateuch, the Book of Jubilees, the Sumerian King List, and Berossus; approximately 40 years of study by the author, built on machine-verified arithmetic and strict claim-status labeling.

## Contents

| Path | Contents |
|---|---|
| `File_00 ... File_70` and Supplement A | 76 canonical public-clean Markdown research files (including split files) |
| `control/` | The four active control documents: Repository Style Guide, Restart Capsule, Project Procedures, State Vocabulary Register |
| `archive/` | Repository Change Archive (non-controlling revision history) |
| `manifest/` | Publication Manifest v29 (CSV/XLSX), with earlier manifests retained as historical records |
| `index.html` | Unchanged canonical source index captured September 30, 2026 |
| `preservation/2026-09-30/` | Source URLs, capture metadata, repository-path inventory, and SHA-256 checksums |

The Markdown files are the **canonical source layer**; WordPress pages, PDFs, and other formats at 490d.com are derived publication layers.

## Reading order

Start with `File_00` (Repository Foundation, Axiom Engine, and Source Map) and the four control documents in `control/`, which define the reading rules, state vocabulary, and claim-status conventions used throughout the corpus.
